# 📊 Global Sales Performance Dashboard — Excel

## 🔍 Project Overview
Analyzed 50,000+ rows of global sales data to build
an interactive dashboard using Microsoft Excel.

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables & Pivot Charts
- Power Query
- Slicers for interactivity

## 📈 Key Insights
- Technology category has highest profit (₹6,63,779)
- central region leads in total sales (₹28,22,399)
- Overall profit margin is only 11.62%
- Consumer segment contributes 51% of total sales
- Top customer: Tom Ashbrook with ₹40,489 in sales

 
## ✅ Skills Demonstrated
- Data Cleaning & Transformation
- KPI Tracking & Reporting
- Dashboard Creation
- Pivot Tables & Slicers
- Business Insights & Analysis
